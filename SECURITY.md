# Security Policy

## Supported versions

Only the latest minor version is supported. Vulnerabilities found in older versions are fixed in the latest version.

## Reporting a vulnerability

Report vulnerabilities through GitHub's Private vulnerability reporting. Open the Security tab of this repository and create a report from "Report a vulnerability".

Keep vulnerabilities out of regular Issues, Discussions, and Pull Requests.

## Response time

We reply to each report within 7 days. We tell you when a fix will land case by case, depending on the severity.
